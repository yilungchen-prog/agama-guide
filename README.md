# 老陳的原始佛學指南

網頁版的《老陳的原始佛學指南》：入門篇（導論、第一至八章、結語）、實修篇（第九至十六章）、延伸篇（第十七章）。

## 檔案結構

- `index.html`：程式（版面、目錄、章節切換、名詞小卡、圖解繪製、互動演練）
- `content/chapters.json`：章節清單（順序、名稱、檔案）。新增一章就在這裡加一行
- `content/*.html`：每一章的內文
- `content/glossary.json`：名詞小卡
- `content/diagrams.json`：所有圖解的資料
- `content/drills.json`：互動演練的情境
